Ouroboros 指南

Ouroboros 管理 AI 编码工作的需求、执行、评估和记录。你的编码 agent（Claude Code、Codex）写代码，Ouroboros 在开工前把规约钉住，在收工后验证结果。

先看这三份

1中文 README它是什么、怎么装、13 个运行时怎么接。 2隐藏清单收敛（设计说明）run 到评估到有预算的演化链，以及判分断言为什么对 worker 隐藏。 3循环工程为什么 agent 循环会「刷分」，以及怎么让它真正收敛。

装上试一下

在终端里跑：

claude plugin marketplace add Q00/ouroboros
claude plugin install ouroboros@ouroboros

需要 Claude Code，不需要 Python。想要独立的命令行工具就用 pip install ouroboros-ai，详见安装章节。

一句话说清楚它做什么

你给一句话需求，它先反问，把模糊度打成分数；访谈还开着的时候，分数高于阈值会挡住规约生成——绕过的路有两条：显式强制（force），或者把访谈标记为完成。规约定下来之后，一条命令驱动执行、分层评估和有预算上限的演化循环（三层齐跑只在直接评估那条路径上成立，演化循环里只跑 Semantic 一层）。当一条验收标准定义了自己的验证命令或期望输出时，那些值不会进执行 agent 的契约块，所以卡住的 agent 没法直接去糊弄断言字符串。
