Start with a small task

Choose the installation path for your coding environment. The example below uses Claude Code; the product getting-started guide also covers Codex and the standalone CLI.

  1. Install the Claude Code plugin and its prerequisites, then open a Claude Code session.
  2. Run ooo setup in that session, then start with ooo interview "Build a task management CLI".
  3. Answer the questions and review the resulting Seed and its acceptance criteria before execution.
  4. After execution, inspect the work and evaluation against your goal. A completed run or evaluation is evidence to review, not a substitute for your own judgment.

Need help? Start with the troubleshooting guide or check the product issues. The site guide describes version 0.51.5, so compare it with your installed version and the current product documentation.

Four separate runs, four hosts. Different tasks on purpose — the engine is what is shared, not the prompt.

Install

Run in your terminal:

zsh
claude plugin marketplace add Q00/ouroboros
claude plugin install ouroboros@ouroboros

Requires Claude Code and uv on the host. See the current installation instructions for prerequisites and other environments, including the standalone CLI. The site install chapter covers the guide’s earlier version.
