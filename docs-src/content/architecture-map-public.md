# 코드 영역 지도

이 지도는 Ouroboros의 코드 영역을 찾기 위한 출발점입니다. 기준은 공개 소스 commit [`722172ef096767583679d04aef5e847458fee6b2`](https://github.com/Q00/ouroboros/tree/722172ef096767583679d04aef5e847458fee6b2)입니다. 아래는 그 커밋의 `src/ouroboros/` 직계 디렉터리 40개와 대표 책임·구현을 보여 줍니다. 한 디렉터리가 여러 책임을 가질 수 있으며, 대표 파일 하나가 전체 기능이나 공개 API의 안정성을 보증하지는 않습니다.

**이 페이지는 기존 상세 지도의 공개용 축약본입니다.** 기존 지도의 세부 구조·연구 연결 및 파일별 지도는 여기에 모두 포함하지 않았습니다. 파일 수준의 전체 지도는 현재 이 문서 허브에서 제공하지 않습니다. 필요하면 [고정 소스 트리](https://github.com/Q00/ouroboros/tree/722172ef096767583679d04aef5e847458fee6b2/src/ouroboros/)에서 직접 파일을 확인하세요. 이 지도는 제품 전체 기능이나 모든 파일의 목록이라고 주장하지 않습니다.

기존 지도는 위 고정 커밋을 기준으로 조사했습니다. 제품 main `592c667f076c3dad7ef68d7844e91480d80135d0`의 직계 디렉터리 이름 집합은 조사 시 같았지만, 내부 구현·공개 release `0.59.9`·설치된 호스트와 서버가 동등하다는 뜻은 아닙니다. 실제 사용 시 설치된 버전과 해당 소스를 확인하세요. 실제 모델·인증·외부 서비스와 모든 운영 조합은 이 지도로 검증하지 않았습니다. [판본과 확인 범위](/docs/version-guide/)

전체 구성 요소의 관계는 [구조와 실행 흐름](/docs/architecture-detail/), 실행 입력과 동작은 [CLI 참조](/docs/cli-reference-detail/)와 [MCP 참조](/docs/mcp-reference-detail/)에서 이어서 볼 수 있습니다.
