# Ouroboros 문서

Ouroboros는 AI 코딩 작업의 목표와 완료 조건을 정리하고, 실행과 평가를 살펴보도록 돕습니다. 코딩 에이전트로 새 작업을 시작하거나 기존 프로젝트의 변경을 관리하는 사람을 위한 안내입니다.

처음이라면 [빠른 시작](/docs/quickstart/)에서 설치 경로를 고르고 작은 할 일 앱의 목표부터 결과 확인까지 따라가세요. 실행 후에는 생성된 파일과 테스트, 평가 결과를 직접 확인합니다.

## 문서와 설치 버전

[빠른 시작](/docs/quickstart/)은 확인한 개발 소스를 기준으로 작성한 초안입니다. 공개 릴리스 `0.59.9`나 설치한 플러그인·연결된 MCP 서버와 다를 수 있습니다. 설치한 경로의 버전과 도움말을 확인하고, 차이가 있으면 해당 버전의 문서를 우선 확인하세요. 기존 한국어·영어 학습 가이드는 `0.51.5`, 기존 상세 참조는 이전 소스 기준입니다. [판본과 검증 범위](/docs/version-guide/#version-scope)
